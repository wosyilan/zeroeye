# Contributing

## Setup
```bash
git clone https://github.com/lobster-trap/zeroeye.git
cd zeroeye
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Guidelines
- Follow PEP 8
- Write tests for new features
- Update docs as needed

## PR Process
1. Fork the repo
2. Create a feature branch
3. Commit changes
4. Open a PR
